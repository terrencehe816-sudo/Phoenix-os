📲 Mobile Sync

text transfer · no account, no server

Everything in this app lives in the browser it runs in, so your laptop and phone each hold their own copy. This section moves data between them as plain text — build a block here, send it to yourself in a note, paste it into this same section on the other device. Nothing leaves your devices except through whatever you use to send the text.

1 Build below 2 ⧉ Copy 3 Send it to the other device 4 Paste + import there

WHAT TRAVELS Workout lines — one line per logged workout, carrying its sets, drill order, categories, RPE, spot rows and its own id, so pasting them back reproduces the workout exactly and re-pasting updates it instead of duplicating it. Full backup code — your whole app (school, goals, habits, playbook, presets) packed into one line. The code is compressed, so it is roughly a quarter of the length a plain copy would be; older PHOENIX1- codes still import. Either way it is plain text — it survives Notes, Messages, email, AirDrop and a QR-free copy/paste. A code that gets line-wrapped on the way still imports.

⇩ Phone → Laptop

one workout per line · court spots supported

Paste notes from your phone — or a compressed backup code built on it. Workout lines become their own saved workouts (never one giant combined day block), and a line copied out of this section pastes back exactly: same drill order, same set types, categories, RPE, individual lift sets and spot rows. The id in each line means pasting the same block twice updates those workouts in place instead of duplicating them.
